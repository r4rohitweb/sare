# The Rack imagery

Sixteen hanging garment cutouts created with the built-in imagegen tool with transparent background enabled. The four-column, four-row atlas was divided into equal cells, cropped to the visible garment with padding, and encoded as WebP while preserving the original alpha channel.

Assets: `rack-blue.webp`, `rack-pink.webp`, `rack-purple.webp`, `rack-green.webp`, `rack-orange.webp`, `rack-maroon.webp`, `rack-yellow.webp`, `rack-teal.webp`, `rack-half-malli.webp`, `rack-half-surya.webp`, `rack-half-ananya.webp`, `rack-half-kaveri.webp`, `rack-blouse-green.webp`, `rack-blouse-pink.webp`, `rack-blouse-blue.webp`, `rack-blouse-gold.webp`.

These are generated style references, not a live inventory. Garment movement, hanger sway, and focused selection are implemented in JavaScript and CSS.
