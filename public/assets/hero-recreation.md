# Archived recreated hero sequence

The current hero uses the user-supplied video documented in `hero-user-video.md`. The six obsolete still poses listed below were removed during project cleanup; this document preserves their provenance. The implementation details below describe the earlier version.

Generated with the built-in imagegen tool using `showroom-seated.webp` as a visual reference and a generated six-panel storyboard. These are six new still photographs, not restored source footage or generated video. The women, room and fabric vary slightly between poses.

The browser shows exactly one fully opaque pose at a time, adds a small camera push, and reverses on backward scrolling. Crossfades are disabled to avoid translucent double images. The six pose changes are discrete; the camera movement stays continuous. A frame-rate-independent 100 ms smoothing response softens abrupt wheel and touch changes; the animation loop stops once settled. The original recorded-screen clip is no longer loaded by the hero. Existing stills remain the image-error fallback; reduced motion retains the original static opening. All story captions are native HTML, without burned-in text.

Assets: `hero-recreated-01.webp` through `hero-recreated-06.webp`, each 1672 x 941 pixels. WebP conversion preserves the generated dimensions.
